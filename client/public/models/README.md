# Browser pose models

`pose_landmarker_lite.task` is the Google MediaPipe Pose Landmarker Lite model used only for browser-side live guidance.

- Source: `https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/latest/pose_landmarker_lite.task`
- SHA-256: `59929E1D1EE95287735DDD833B19CF4AC46D29BC7AFDDBBF6753C459690D574A`
- The checkpoint does not calculate or persist the clinical exercise evaluation score. Recorded evaluation continues to use the registered YOLO/Transformer pipeline.
